# 📅 NNTU Schedule & Labs Tracker Bot

Telegram-бот для автоматизации расписания и трекинга лабораторных работ студентов НГТУ им. Р.Е. Алексеева. Проект разработан специально для группы **26-ИВТ-2-1**.

## 🚀 Основной функционал

- **Универсальный трекер лаб с сентября:** Полный учет и вывод всех лабораторных работ с начала учебного года (без ограничений в 14 дней для хвостов семестра).
- **Разделение по подгруппам:** Персонализированный вывод лабораторных работ под конкретную подгруппу студента (всего 3 подгруппы).
- **Индивидуальный учет сдачи:** Возможность для каждого пользователя отметить лабу как выполненную с помощью инлайн-кнопки `✅ Отметить как сданную`.
- **Фильтрация и авто-удаление:**
  - `🔴 [ПРОСРОЧЕНО / ДОЛГ]` — лаба не сдана, а дедлайн уже прошел. Висит в списке, пока юзер не нажмет кнопку.
  - `⏳ [АКТУАЛЬНО]` — лаба не сдана, дедлайн в будущем (в пределах 14 дней). Более поздние работы временно скрыты.
  - `🟢 [СДАНО]` — лаба отмечена как сданная, но день ее дедлайна еще не наступил (для наглядности прогресса).
  - **Авто-исключение:** Сданная лаба полностью исчезает из вывода сразу после наступления или прохождения дня её дедлайна. Если лаба сдана уже после дедлайна (закрыт долг) — сообщение удаляется мгновенно.
- **Хэндлер-ловушка (Anti-Flood):** Мгновенное удаление любого текстового флуда от пользователей в обход кнопок для сохранения чистоты чата (работает даже при активном FSM-состоянии).

## 🛠 Стек технологий

- **Язык:** Python 3.11+
- **Фреймворк:** `aiogram 3.x` (Asynchronous Telegram Bot API)
- **База данных:** `SQLite3` (таблицы для расписания и связи `user_completed_labs`)
- **Архитектура:** Модульная структура (`handlers/`, `keyboards/`, `db_manager.py`, `parser.py`).

## 💻 Локальный запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd nntu-schedule-bot
   ```

2. **Настройте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл конфигурации окружения:**
   В корне проекта создайте файл `.env` и добавьте токен бота:
   ```env
   BOT_TOKEN=your_telegram_bot_token_here
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```
